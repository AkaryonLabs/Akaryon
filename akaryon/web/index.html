Runtime & devices

Settings checks this site's microphone permission and input-device availability only; it never requests audio or starts capture. Windows app aliases are optional and every open or graceful close needs approval. Codex CLI stays disabled until its compatibility, sign-in, and Windows sandbox checks pass.

Voice playback

Playback uses voices provided by your browser or operating system. Available voices and their processing vary by device.

Provider setup & integrations

Provider keys live in dist\.env for the packaged build, or `.env` for a source run. This page deliberately never reads or displays secret values.

  1. Stop Akaryon before changing provider settings.
  2. Update the provider and model in the local environment file.
  3. Restart Akaryon and confirm the active model above.

Changing the provider does not erase conversations, projects, or database records.
